> **Vela** — это open-source, с приоритетом на приватность и локальную работу, ИИ-редактор для написания романов, созданный специально для **длинных произведений**, **веб-фика** и **художественного писательства**. Он глубоко интегрирует ИИ-пайплайны (генерация плана,起草 глав, умная переработка, автоматическая рецензия) с локальной RAG-базой знаний, предоставляя авторам погружающий творческий опыт уровня IDE — всё работает на вашем компьютере с вашими собственными ключами API (BYOK).

## Ключевые возможности

Vela — это не просто текстовый редактор с чатом, а **производственный движок для написания романов**, который глубоко интегрирует возможности ИИ, долгосрочное контекстное извлечение (RAG) и автоматизированные пайплайны для создания художественной литературы.

### ИИ-пайплайн для написания романов

| Возможность | Описание |
|---|---|
| Миростроительство | Пользовательские глобальные настройки мира, оси основного сюжета, профили персонажей (с динамическим отслеживанием состояний между главами) |
| Автогенерация плана | Однокнопочная генерация ИИ: «структурный скелет → планы глав → требования к сценам/эмоциям/ритму», поддерживает трёхактную, «Путешествие героя» и другие нарративные структуры |
| Черновик главы | Потоковая генерация одной главы с точным учётом предыдущего контекста и плана, можно остановить в любой момент |
| ИИ-переработка | Переработка на уровне абзацев или целой главы с сохранением консистентности персонажей и сюжета |
| Шлифовка | ИИ автоматически обнаруживает грамматические ошибки, опечатки и логические дыры, выдавая отполированные предложения |
| Рецензия | ИИ оценивает главы с точки зрения читателя/редактора, выявляя проблемы темпа, дуг персонажей и зацепок |
| Тройной пайплайн постобработки | Переработка → Шлифовка → Рецензия — трёхступенчатая цепочка для обеспечения высокого качества глав |

### Локальная база знаний RAG на миллион слов

| Возможность | Описание |
|---|---|
| Массовый импорт | Однокнопочный импорт миллионов слов эталонных романов, документов о настройках мира, сборников персонажей |
| Векторный семантический поиск | Автоматически извлекает наиболее релевантные фрагменты настроек на основе семантики текущей главы — больше никаких несоответствий персонажей/настроек |
| Чистое локальное хранение | Встроенный SQLite + лёгкий векторный движок, все данные хранятся локально, работает офлайн |

### Расширяемая архитектура

| Возможность | Описание |
|---|---|
| BYOK (Свои ключи) | Нативная совместимость с OpenAI, DeepSeek, Gemini, Claude, Ollama (локальный офлайн), Zhipu GLM и др. Умная маршрутизация: DeepSeek для планов, Claude для полировки, локальные модели для приватной проверки |
| Протокол MCP | Нативная интеграция Model Context Protocol, подключение пользовательских серверов инструментов для расширения возможностей ИИ |
| Аналитика использования | Встроенная панель статистики: вызовы LLM, потребление токенов, тенденции стоимости |

### Редактор уровня IDE

| Возможность | Описание |
|---|---|
| Настраиваемые панели | Дерево файлов + редактор + панель ИИ + нижний терминал, гибкая комбинация как в VSCode/JetBrains |
| Тёмная тема | Оптимизированный тёмный режим с пользовательской плавающей строкой заголовка и микроинтеракциями строки состояния |
| Горячие клавиши | Глобальные сочетания: Cmd+N новое, Cmd+O открыть, Cmd+=/- масштаб |
| Кроссплатформенность | macOS (dmg) / Windows (nsis) / Linux (AppImage) |

## Установка

### Прямое скачивание

Перейдите в [Releases](https://github.com/Izya12/vela/releases) для скачивания последней версии:
- **macOS**: `.dmg` установщик
- **Windows**: `.exe` установщик (NSIS)

### Сборка из исходников

```bash
# Требования: Node.js >= 18, npm >= 9

# 1. Клонировать проект
git clone https://github.com/Izya12/vela.git
cd vela

# 2. Установить зависимости
npm install

# 3. Запустить сервер разработки (с горячей перезагрузкой)
npm run dev

# 4. Собрать для распространения
npm run build
```

> **Примечание**: Необходимы инструменты сборки для нативных модулей SQLite (macOS: Xcode Command Line Tools, Windows: Visual Studio Build Tools).

## Настройка моделей

Vela поддерживает множество основных провайдеров LLM. Быстрая настройка:

1. Откройте приложение → нажмите **Настройки** в левом нижнем углу
2. Перейдите в **Настройки моделей**
3. Нажмите **Добавить модель**:
   - Выберите провайдер: OpenAI / DeepSeek / Gemini / Ollama / Zhipu / Пользовательский
   - Заполните `API-ключ` и `Базовый URL` (при использовании прокси)
   - Назначьте рекомендованные модели для разных задач (написание / полировка / Embedding-поиск)
4. **Начинайте писать!**

**Поддерживаемые провайдеры LLM:**

`OpenAI` · `DeepSeek` · `Google Gemini` · `Anthropic Claude` · `Ollama (Локальный)` · `Zhipu GLM` · `MiniMax` · `SiliconFlow` · `Любой API, совместимый с OpenAI`
